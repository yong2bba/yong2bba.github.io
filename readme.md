# yong2bba.github.io

Yongjin의 한국어 개인 블로그입니다. Astroplate를 기반으로 하며 GitHub Pages에 정적으로 배포합니다.

## Development

```bash
pnpm install
pnpm build
pnpm check
pnpm dev
```

## Content

글은 `src/content/blog/` 아래의 Markdown 또는 MDX 파일로 관리합니다.

## Deployment

`main` 브랜치에 병합하면 GitHub Actions가 `https://yong2bba.github.io/`에 배포합니다.
